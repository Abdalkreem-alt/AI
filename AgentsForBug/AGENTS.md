# AGENTS.md — working in this repo

Guidance for the MultiHunter agent team (and the AI tools running in this repo).

## What this repo is

- `agents/` — the opencode subagent definitions. The body of each file is the
  agent's standing prompt; the frontmatter is opencode config (`mode`,
  `permission`, ...). Keep prompt files self-contained: they must make sense
  when rendered alone by `mh run <target> <stage>`.
- `orchestrator/` — stdlib-only Python. `blackboard.py` is the state API;
  `cli.py` is the `mh` CLI; `dedup.py`, `reportgen.py`, `promptlib.py` are
  helpers. No third-party imports.
- `skills/multi-hunter/` — the coordinating skill (workflow + blackboard +
  handoff contract).
- `commands/` — opencode slash commands (`/pipeline`, `/mh-status`, `/mh-scope`).
- `knowledge/` — vendored Claude-BugHunter content (`cbh-skills/`,
  `cbh-reports/`). Regenerated by `scripts/vendor-skills.*`; do not hand-edit.
- `tests/` — stdlib `unittest`, run with `python -m unittest discover -s tests`.

## Rules

1. **Stdlib only** in `orchestrator/`. If you need a dependency, ask first.
2. **Every agent ends with the handoff JSON** (fenced ```json``` block) — the
   Director parses it. Keep the schema: `agent`, `status`, `counts`,
   `artifacts_written`, `highlights`, `recommended_next`, `blockers`.
3. **Scope discipline is not optional** — agents only test assets in the
   engagement's `scope.json`. Out-of-scope discoveries are noted, not probed.
4. **Redact everything** — cookies, tokens, and third-party PII never appear in
   artifacts or findings.
5. **Never fabricate evidence.** A test that did not run is a `blocker`, not a
   result.
6. **Don't clobber other stages' artifacts.** Append via `mh ingest`; write your
   own stage's outputs directly.
7. **Changes to agents/commands/skills require an opencode restart** to take
   effect. `mh` CLI changes do not.

## Verify

After touching Python or prompts: `python -m unittest discover -s tests -v`.
The promptlib test asserts every agent prompt renders with a blackboard
snapshot and a handoff contract.
