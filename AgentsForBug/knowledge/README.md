# knowledge/

The vendored Claude-BugHunter knowledge layer that backs the MultiHunter agent
team. Regenerated by `scripts/vendor-skills.ps1` / `scripts/vendor-skills.sh`
from a clone of <https://github.com/elementalsouls/Claude-BugHunter>.

| Directory | Contents | License |
|---|---|---|
| `cbh-skills/` | 83 Agent-Skills (the per-class `hunt-*` encyclopedia, recon, triage, evidence hygiene, reporting) | MIT (code) + CC BY 4.0 (methodology/content) |
| `cbh-reports/` | 37 disclosed-report pattern libraries across 24 vulnerability classes | CC BY 4.0 |

Do not hand-edit these directories — re-run the vendor script to refresh.
Install copies `cbh-skills/` into `~/.agents/skills/` where opencode scans them
automatically, making every specialist able to load the right skill on demand.
